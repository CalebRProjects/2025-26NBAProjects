# 2025–26 NBA Analytics Projects

This repository is a collection of in-season NBA analytics projects built with reproducible R workflows. The projects combine data collection, cleaning, visualization, statistical framing, and basketball writing to turn player/team trends into readable analysis.

Most folders include some combination of:
- an R Markdown analysis file
- a knitted PDF report
- a project README
- cleaned outputs or visual assets

These projects support my work with TipOffBall, where selected analyses are adapted into social graphics, threads, and public-facing basketball stories.

## Tools & Data

**Tools:** R, tidyverse, ggplot2, R Markdown, Quarto, Git/GitHub  
**Data sources:** NBA.com, Synergy, Cleaning the Glass, StatMuse, DataBallr, and other publicly available basketball data sources

Some source data is proprietary or restricted, so certain folders may include methodology, visuals, summaries, or rendered reports rather than raw datasets.

## Purpose

The goal of this repo is to document the full analytical workflow behind public basketball analysis: identifying a question, pulling and cleaning data, building visuals, writing the interpretation, and producing outputs that can be reviewed technically or adapted for a broader audience.
